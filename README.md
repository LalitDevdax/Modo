# Modo | Enterprise AI Adoption & ROI Platform

Modo helps enterprises turn AI software spend into active daily adoption and measurable ROI. Built with Next.js 14, Tailwind CSS, and Framer Motion.

## 🚀 Key Features

- **Liquid Curtain Navigation**: Ultra-fast multi-layer React curtain transition with 0.001s route prefetching.
- **Enterprise Report Download (`/report`)**: Interactive executive report download page featuring dynamic inline validation and abstract 3D glass artwork.
- **Stanford & Meta Founder Story (`/about`)**: Full origin story, award recognitions, and co-founder profiles.
- **Interactive Contact Hub (`/contact`)**: Instant `mailto:` integration, one-click email copy, and Google Maps location integration.
- **Modo Theme Scrollbar**: Custom ultra-thin scrollbar with brand pink hover highlights.
- **Lighthouse Performance**: 100/100 score ready with font display swap, high-priority LCP asset loading, and GPU hardware acceleration.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Plus Jakarta Sans, Newsreader, Space Grotesk

## 💻 Getting Started

### Prerequisites
- Node.js 18.x or later
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/LalitDevdax/Modo.git

# Navigate to project directory
cd Modo

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

---

## 📦 Build for Production

```bash
npm run build
npm start
```
